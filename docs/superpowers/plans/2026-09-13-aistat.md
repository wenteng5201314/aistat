# aistat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可安裝、可測試、能在 macOS Apple Silicon 優雅降級的 `aistat` 終端機 AI 儀表板。

**Architecture:** 使用單一 Bash 主程式，將每個資料來源封裝成獨立函式；測試透過臨時 PATH 注入假的 macOS/Ollama/Docker 指令。安裝器只複製主程式，不修改 shell 設定或要求 sudo。

**Tech Stack:** Bash 3.2 相容語法、awk、sed、macOS `vm_stat`／`sysctl`／`memory_pressure`／`powermetrics`、Ollama CLI、Docker CLI。

**Spec:** `docs/superpowers/specs/2026-09-13-aistat-design.md`

## Global Constraints

- 僅支援 macOS Apple Silicon，非 macOS 平台須清楚顯示不支援並以非零狀態退出。
- 主程式不得修改系統設定、停止模型或容器、保存任何系統資料。
- 任一選用資料來源失敗時，其餘區塊仍須輸出。
- 預設不得觸發互動式 sudo；只有明確傳入 `--gpu` 才可呼叫 sudo。
- Bash 程式必須相容 macOS 內建 Bash 3.2，不使用關聯陣列或 Bash 4 專屬語法。
- 沒有終端輸出、設定 `NO_COLOR` 或傳入 `--no-color` 時不得輸出 ANSI 色碼。
- 這個資料夾不是 Git 專案，因此省略提交步驟，不自行初始化 Git。

### Task 2: 記憶體數值與 Memory Pressure

**Files:**
- Modify: `aistat`
- Modify: `tests/run.sh`
- Create: `tests/fixtures/vm_stat.txt`
- Create: `tests/fixtures/memory_pressure.txt`

**Interfaces:**
- Consumes: `sysctl -n hw.memsize`、`sysctl vm.swapusage`、`vm_stat`、`memory_pressure`。
- Produces: `bytes_human BYTES`、`vm_pages LABEL TEXT`、`print_memory`、`print_pressure`、`pressure_level FREE_PERCENT`。

- [ ] **Step 1: 建立容量計算與三色門檻的失敗測試**

使用固定 4096-byte page fixture，包含 free、active、inactive、speculative、wired、purgeable、compressed pages；假的 `sysctl` 回傳 36 GiB 與 `used = 6.36G`。斷言總量為 `36.0 GiB`，並依公式檢查 Used、App、Wired、Compressed 與 Swap。分別以 free percentage 25、15、5 測試 `正常`、`注意`、`嚴重`，並以 `AISTAT_FORCE_COLOR=1` 驗證對應 `32m`、`33m`、`31m` 色碼；`NO_COLOR=1` 時驗證沒有 ESC 字元。

- [ ] **Step 2: 驗證新增測試因函式／輸出尚未存在而失敗**

Run: `rtk bash tests/run.sh`

Expected: FAIL，缺少 Memory 與 Pressure 欄位。

- [ ] **Step 3: 實作記憶體解析與狀態顏色**

以 awk 從 `vm_stat` 第一列取得 page size，移除數值尾端句點後換算 bytes。App 以 active + inactive + speculative + compressed 估算；Used 以 total - free - inactive - speculative - purgeable 計算且下限為零。`memory_pressure` 無百分比時，用 `vm_stat` 的可回收頁面比例後備估算並在標籤加上 `估算`。

- [ ] **Step 4: 執行全部測試並確認通過**

Run: `rtk bash tests/run.sh`

Expected: Task 1 與 Task 2 測試全部 PASS。

### Task 3: Docker 與 GPU 權限降級

**Files:**
- Modify: `aistat`
- Modify: `tests/run.sh`
- Create: `tests/fixtures/docker-stats.txt`
- Create: `tests/fixtures/powermetrics.txt`

**Interfaces:**
- Consumes: `docker info`、`docker stats --no-stream --format ...`、`sudo -n true`、`powermetrics --samplers gpu_power -n 1`。
- Produces: `print_docker`、`print_gpu INTERACTIVE_GPU`。

- [ ] **Step 1: 建立 Docker 與 GPU 降級失敗測試**

假的 Docker 成功時回傳 `ollama-webui\t1.2GiB / 4GiB\t30.00%`，失敗時斷言顯示 `Docker 引擎未執行`。假的 `sudo -n true` 失敗時，無參數執行須顯示 GPU 權限提示且不中斷；成功時解析 fixture 的 `GPU HW active residency: 16.67%`。傳入 `--gpu` 時，斷言呼叫的是允許互動的 `sudo powermetrics` 路徑。

- [ ] **Step 2: 驗證新增測試因區塊不存在而失敗**

Run: `rtk bash tests/run.sh`

Expected: FAIL，缺少 Docker/GPU 狀態。

- [ ] **Step 3: 實作 Docker 與 GPU 區塊**

`print_docker` 先檢查指令，再用 `docker info >/dev/null 2>&1` 判斷引擎，最後輸出固定格式 stats。`print_gpu` 先檢查 `powermetrics`；預設只在 `sudo -n true` 成功後執行 `sudo -n powermetrics`，明確 `--gpu` 時才執行 `sudo powermetrics`。命令失敗或輸出格式不符時顯示原因，不回傳整體失敗。

- [ ] **Step 4: 執行全部測試並確認通過**

Run: `rtk bash tests/run.sh`

Expected: 所有功能測試 PASS，且測試期間沒有真實 sudo 提示。

### Task 4: 安裝器、README 與端對端驗證

**Files:**
- Create: `install.sh`
- Create: `README.md`
- Modify: `tests/run.sh`

**Interfaces:**
- Consumes: `install.sh [--prefix DIR] [--force]`。
- Produces: 目標目錄中的可執行 `aistat`。

- [ ] **Step 1: 建立安裝器失敗測試**

安裝到 `mktemp -d` 指定的 prefix，斷言 `${PREFIX}/aistat --help` 成功；第二次未加 `--force` 必須失敗且保留原檔，加上 `--force` 必須成功。另以 `bash -n aistat install.sh tests/run.sh` 驗證語法。

- [ ] **Step 2: 驗證測試因 install.sh 不存在而失敗**

Run: `rtk bash tests/run.sh`

Expected: FAIL，原因為安裝器不存在。

- [ ] **Step 3: 實作安全安裝器**

解析 `--prefix` 與 `--force`；指定 prefix 時建立該目錄，未指定時只選擇已存在且可寫的 `/usr/local/bin`，否則建立並使用 `$HOME/.local/bin`。使用 `install -m 0755` 複製與安裝器同目錄的 `aistat`，不呼叫 sudo、不修改 PATH。

- [ ] **Step 4: 撰寫 README**

README 必須包含：功能清單、`./install.sh`、`./install.sh --prefix "$HOME/.local/bin"`、`aistat`、`aistat --gpu`、`NO_COLOR=1 aistat`、卸載方式、資料來源、估算公式、Memory Pressure 門檻、sudo 行為、Docker/Ollama 選用性、macOS 版本輸出可能變動的限制。

Run: `rtk bash tests/run.sh`

Expected: 所有測試 PASS，exit 0。

Run: `rtk bash -n aistat install.sh tests/run.sh`

Expected: 無輸出，exit 0。

- [ ] **Step 6: 在目前 Mac 執行唯讀端對端驗證**

Run: `NO_COLOR=1 ./aistat`

Expected: Ollama、Memory、Docker、GPU、Memory Pressure 五個區塊全部出現；沒有密碼提示。資料來源未安裝或未執行可顯示降級狀態。
